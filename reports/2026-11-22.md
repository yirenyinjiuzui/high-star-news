## Where to start today

For a camera RAW file, start in darktable to set exposure and color. For repeated exports, choose ImageMagick in a shell, Pillow in Python or sharp in a Node.js build. Try OxiPNG when the PNG artwork is already approved and only the download size is open to change.

## 1. ImageMagick

Turn a repeatable image edit into a shell command.

### What it does

Resize, convert and composite images. A single command can apply several operations in order and write a separate output file.

### Why we recommend it

A saved command lets a second person reproduce the same export dimensions next week.

### How it could help you

1. Scale a folder of screenshots to a common width for a manual.
2. Arrange test images into a contact sheet to spot cropping errors.

### Who it fits and what to expect

Free desktop binaries for Windows, macOS and Linux. Suitable for recurring exports. A visual editor is easier for hand retouching. Supported formats depend on the installed delegates, and large images can use temporary disk space.

### A small first step

Allow 15 minutes. On a sample copy, run `magick input.png -resize 800x800 preview.png`. Check the preview dimensions with `magick identify preview.png` and confirm that the aspect ratio is preserved.

## 2. Pillow

Make image layout decisions inside a Python script.

### What it does

Open an image, inspect its dimensions and mode, crop a region, draw labels and save a new file. The Pillow handbook illustrates these operations with small examples.

### Why we recommend it

Choose it when the crop or label depends on a value already computed in Python, such as the page number of a scan.

### How it could help you

1. Crop the same margin from a batch of scanned worksheets.
2. Add the sample ID below each experiment thumbnail.

### Who it fits and what to expect

Free open-source library for supported Python environments on major desktop platforms. It requires scripting and memory for decoded pixels. Check image mode before saving, especially when converting transparent images to JPEG.

### A small first step

Allow 20 minutes. Follow the handbook tutorial to open two images in different orientations, print their sizes, call `thumbnail((320, 320))` on each and save as new PNGs. Compare their longest edges.

## 3. sharp

Generate several web image sizes during a site build.

### What it does

The libvips-based module accepts paths, buffers or streams and can resize, crop and encode common web formats within a Node.js application.

### Why we recommend it

An existing JavaScript build can regenerate thumbnails whenever the source photography changes.

### How it could help you

1. Export a small card thumbnail and a wider article image from one photo.
2. Normalize portrait orientation before generating an image gallery.

### Who it fits and what to expect

Apache-2.0 module with prebuilt packages for common Windows, macOS and Linux targets. Check the supported runtime and architecture before deployment. Concurrent builds share CPU and memory. A desktop editor suits occasional manual crops.

### A small first step

Allow 20 minutes. Adapt the official resize example to write 320- and 960-pixel-wide WebP files from one large JPEG. Compare both at their intended display sizes and record their byte sizes.

## 4. darktable

Develop a camera RAW file and keep its original for later edits.

### What it does

Organize photos in the lighttable, edit exposure and color in the darkroom, then export rendered copies. The editing history lets you revisit earlier decisions.

### Why we recommend it

A photographer can compare treatments of one exposure before committing to a finished JPEG.

### How it could help you

1. Recover detail in a dim foreground and compare it with the original rendering.
2. Apply consistent adjustments to a sequence shot under the same lighting.

### Who it fits and what to expect

Free GPL desktop software with Windows, macOS and Linux packages. Check camera support before importing a collection. Large RAW files need memory and preview storage. The workflow takes more learning than a one-click photo filter.

### A small first step

Allow 25 minutes. Import one supported RAW sample, adjust exposure, compare before and after, then export a small JPEG. Reopen the RAW in darktable and locate the exposure adjustment in its history.

## 5. OxiPNG

Recompress a finished PNG while preserving its pixel content.

### What it does

This multithreaded optimizer searches PNG compression settings. Keeping the original and writing a new output makes it easy to measure the savings for each asset.

### Why we recommend it

Included below the 10,000-star preference because it answers a narrower question than resizing or format conversion. Can an already approved PNG ship in fewer bytes?

### How it could help you

1. Reduce the transfer size of a documentation screenshot with fine text.
2. Check whether a set of UI icons benefits from recompression before release.

### Who it fits and what to expect

MIT-licensed local CLI for Windows, macOS and Linux. Higher effort consumes additional CPU time and an optimized file may barely shrink. Metadata stripping is optional and can affect downstream use. JPEG photographs need a different tool.

### A small first step

Allow 15 minutes. Run `oxipng -o 2 --out smaller.png input.png` on a sample PNG. Compare dimensions and byte sizes. Repeat on a different screenshot before deciding whether to add the step to a build.
