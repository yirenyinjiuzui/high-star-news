## Where to start today

EasyOCR returns locations for labels in a photo. For a table, try PaddleOCR and verify that values land under the correct headings.

## 1. Tesseract

Extract the printed words from a page image.

### What it does

The command-line engine reads images such as PNG, JPEG and TIFF using language-specific data. It can write plain text for editing or TSV containing word positions and confidence values.

### Why we recommend it

It gives you a simple baseline when you know the page language and can check the transcription against the original.

### How it could help you

1. Recover a quotation from a clear scan and check its punctuation before citing it.
2. Compare word positions against a catalog card to locate a misread shelf number.

### Who it fits and what to expect

Apache-2.0 engine available for Linux, macOS and Windows. Local CPU processing needs the matching language data. Small print, skew and multi-column layouts can change the result. A PDF input requires a separate page-rendering step.

### A small first step

Allow 15 minutes with English language data installed. Run `tesseract page.png stdout -l eng` on a printed sample. Compare three lines with the scan, then crop one troublesome line and check whether the same characters are still wrong.

## 2. PaddleOCR

Keep track of where text and tables belong on a complex page.

### What it does

The PP-StructureV3 pipeline analyzes layout and exports structured results such as Markdown or JSON. Its coordinates can help trace a recognized table cell or text region back to the page.

### Why we recommend it

Use it when a correct number would still be misleading if assigned to the wrong row or column.

### How it could help you

1. Extract a timetable and verify that each departure is paired with its destination.
2. Convert a two-column report into reading order and check where a caption appears.

### Who it fits and what to expect

Apache-2.0 toolkit. Choose a supported Python environment, inference backend and model for your hardware. Downloads, memory and processing time depend on the pipeline. A full layout model adds setup for a page containing only one paragraph.

### A small first step

Allow 25–30 minutes once the runtime and weights are ready. Process a single public timetable with PP-StructureV3, inspect its exported table, and trace three cells including one beside a merged heading back to the scan.

## 3. EasyOCR

Find text on a photo and keep the box around each result.

### What it does

The Python reader returns a bounding box, recognized string and confidence score for each detection. A reader can load compatible languages together, including Simplified Chinese and English.

### Why we recommend it

The boxes help a reviewer see which sign or printed label produced a questionable result.

### How it could help you

1. Transcribe bilingual exhibit labels while keeping each label tied to its position.
2. Find a misread digit on a shelf label by comparing its box with the photograph.

### Who it fits and what to expect

Apache-2.0 Python package using PyTorch. A CPU-only reader is available. Model weights need local storage and may download on first use. Language combinations are constrained, and a high score still calls for checking consequential digits.

### A small first step

Allow 20 minutes in a prepared environment. Create `easyocr.Reader(['ch_sim','en'], gpu=False)` and call `readtext` on a photo with three printed labels. Match each returned box to a label and compare all digits, including those in high-scoring results.

## 4. OCRmyPDF

Search a scan while keeping its page image available for inspection.

### What it does

The CLI adds recognized text underneath scanned pages. Options include page rotation and deskewing. The output can be opened in a PDF reader for searching and copying.

### Why we recommend it

Choose it when the reader needs to jump from a search result directly to the original page.

### How it could help you

1. Find a surname across a scanned index and verify its spelling on the page.
2. Make a scanned meeting packet searchable while retaining its figures and page sequence.

### Who it fits and what to expect

MPL-2.0 software for a local command-line environment with the required OCR and PDF dependencies. Large documents need CPU time and temporary disk space. Search quality depends on recognition, and image cleanup can affect the visible page.

### A small first step

Allow 15–20 minutes with dependencies ready. Run `ocrmypdf -l eng scan.pdf searchable.pdf` on a two-page English image-only sample. Search for a distinctive word on each page, copy one line, and compare its spelling with the scan.

## 5. Tesseract.js

Let someone read text from an image inside a web page.

### What it does

The library wraps Tesseract through WebAssembly for browsers and Node.js. Create a worker for a language, recognize multiple images with it, and terminate it after the last one.

### Why we recommend it

It fits a small web tool where the user should be able to correct the transcription immediately after choosing an image.

### How it could help you

1. Put an editable transcription beside an uploaded page image for proofreading.
2. Read several cropped labels in sequence and keep the same language worker warm.

### Who it fits and what to expect

Apache-2.0 library. The browser needs memory for the worker and access to the engine and language assets. Offline use requires making those assets available locally. PDF pages must first be rendered as images. Recognition uses the underlying Tesseract model.

### A small first step

Allow 20–25 minutes. Adapt the official `createWorker('eng')` example to recognize two sample PNGs in sequence. Display both strings with their filenames, verify which output belongs to which image, then terminate the worker.
