## Where to start today

Start with a library’s monthly loans. Chart.js can show the trend on a plain page. Choose ECharts if readers need to zoom or toggle branches, or Recharts if a React page already owns those controls. Vega-Lite makes the aggregation easy to review. D3 gives you control over every endpoint when comparing two months.

## 1. Chart.js

Add a monthly trend to a plain HTML page.

### What it does

Supply month labels and a dataset to a line chart. Chart.js draws into a canvas and can show the value of a point in a tooltip.

### Why we recommend it

A single trend and a few labels fit its built-in chart types with little setup.

### How it could help you

1. Show a library’s monthly loan count beside its annual total.
2. Add a second series for the prior year and compare the same month across years.

### Who it fits and what to expect

MIT-licensed browser library. A local HTML page and the library are sufficient for a small chart. Canvas pixels alone do not give screen readers the underlying values, so include a text summary or data table.

### A small first step

Allow 15 minutes. Adapt the official line example to six months of sample loans. Change one count to zero, then to null. Inspect the difference and label missing observations explicitly.

## 2. Apache ECharts

Let readers explore a time range inside a chart.

### What it does

Configure axes and series in an option object. A dataZoom control narrows the displayed range, while a legend lets readers choose which series remain visible.

### Why we recommend it

It suits a dashboard where someone needs to move between a long history and a few months without losing the other branches for comparison.

### How it could help you

1. Zoom to the months around a branch renovation to inspect a temporary drop.
2. Hide the largest branch so changes at two smaller branches are easier to see.

### Who it fits and what to expect

Apache-2.0 library for web pages, available as a download or npm package. It needs a chart container with a defined size. Dense data and many series warrant testing on the intended device.

### A small first step

Allow 20 minutes. Adapt a line-chart example to two branches and twelve months, add a slider dataZoom, then narrow it to one quarter. Check the month labels and tooltips at both ends.

## 3. Vega-Lite

Describe a chart in a text specification that a colleague can review.

### What it does

Map fields to position and color, choose a mark and specify aggregations. Vega-Lite compiles the description into a Vega specification. The official browser editor can render a small inline dataset.

### Why we recommend it

Included below the usual star threshold because its compact specification makes an analytical choice, such as summing by branch, visible in a review.

### How it could help you

1. Review whether a branch comparison uses total or average monthly loans.
2. Reuse one specification with next quarter’s records and inspect the changes in version control.

### Who it fits and what to expect

BSD-3-Clause software. The web editor is enough for a first exercise. Embedding a chart requires the Vega runtime and a compatible embedding setup. Highly bespoke layouts can exceed the grammar’s convenient defaults.

### A small first step

Allow 20 minutes. Open the official bar example in Vega Editor, enter six sample rows with branch and count fields, and encode the sum by branch. Switch sum to mean and explain the changed axis units.

## 4. Recharts

Keep a chart and its surrounding React controls on the same data.

### What it does

Compose an SVG chart from React components for axes, lines, grids and tooltips. Pass records to the chart and bind a series to a field with dataKey.

### Why we recommend it

It is a natural fit when the page already has a branch selector and the same selection should update the chart and a table.

### How it could help you

1. Drive a detail chart from the selected branch in a dashboard.
2. Reuse one chart component for loans and returns by passing different series keys.

### Who it fits and what to expect

MIT-licensed React library. Match react-is to the installed React version. Check the dimensions of the parent when using a responsive container. Adding React solely for one chart entails extra setup.

### A small first step

Allow 20 minutes in a React project. Feed six monthly records to a LineChart. Add a selector for loans or returns and have a small table show the same field. After switching, compare the last value in each view.

## 5. D3

Build a chart whose geometry or labels need individual control.

### What it does

Scales map values to positions, and a data join associates records with elements. You can use these pieces to draw and update marks in an SVG without adopting a preset chart layout.

### Why we recommend it

Consider D3 when the placement of a label or the way two values are connected carries part of the story.

### How it could help you

1. Connect January and June counts for each branch with a slope line.
2. Label branch names next to the endpoints and highlight one branch with a distinct stroke.

### Who it fits and what to expect

Free ISC-licensed JavaScript library for the web. A browser and basic SVG knowledge are enough for the exercise. Layout, label collisions and keyboard interaction need explicit design, which adds work for a routine chart.

### A small first step

Allow 30 minutes if you know SVG. Use three branches and two months. Map counts to a common vertical scale, draw one line per branch and label its June endpoint. Try two equal June counts and inspect the overlap.
