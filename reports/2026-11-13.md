## 1. marimo

Keep dependent calculations connected to the inputs they use.

### What it does

Reactive Python notebooks stored as .py files: changing a cell or UI value reruns dependent cells, or marks them stale in a lazy configuration. Notebooks can also run as scripts or apps.

### Why we recommend it

Recommended when manual cell reruns make it hard to track which results match current inputs. Dependency tracking helps manage execution order but does not establish that the analysis itself is correct.

### How it could help you

1. Use a slider to vary a harmless parameter and inspect dependent outputs.
2. Review a notebook's .py diff alongside a change in a calculation.

### Who it fits and what to expect

Apache-2.0 software for compatible Python environments on Windows, macOS and Linux, with a browser editor. Needs RAM/CPU for your code; no GPU for a tiny example. Optional AI APIs and hosting have separate costs. Existing Jupyter workflows may need adaptation. Automatic reruns can repeat expensive or external side effects; configure lazy behavior where appropriate.

### A small first step

20–30 minutes: follow https://docs.marimo.io/ and the intro tutorial. Build three tiny cells: one input, one calculation and one output. Change the input and observe dependencies, then inspect the saved Python file. Use only local, harmless calculations in the first trial.

## 2. NumPy

Represent numerical data as arrays and calculate across dimensions.

### What it does

Provides N-dimensional arrays, broadcasting, linear algebra, Fourier transforms and random-number capabilities. It underpins many scientific Python workflows but is useful directly for small, explicit calculations.

### Why we recommend it

Recommended for learning shapes, axes and vectorized operations before adding a larger data or modeling framework. Correct dimensions and data types matter more than shorter syntax.

### How it could help you

1. Compute column summaries for a small fabricated measurements matrix.
2. Compare a matrix operation with a hand-worked two-by-two example.

### Who it fits and what to expect

Free scientific Python package; check the repository license and bundled dependency notices. Compatible wheels exist for major OSs and supported Python versions. CPU/RAM and temporary array storage grow with data; standard use does not require a GPU. Not symbolic algebra or a spreadsheet UI. Broadcasting can silently express the wrong calculation if shapes are misunderstood; floating-point values are approximate.

### A small first step

15–25 minutes: follow https://numpy.org/doc/ with a 2-by-3 array. Print its shape and dtype, calculate row and column sums and compare each with manual totals. Try one deliberate shape mismatch and read the error before using larger data.

## 3. SymPy

Work with expressions as symbols before substituting numbers.

### What it does

A Python symbolic-mathematics library. The README demonstrates exact symbolic expressions and series expansion; its documentation covers the supported algebraic operations and assumptions.

### Why we recommend it

Useful for checking a small derivation or obtaining an expression that remains parameterized. Symbolic output should be interpreted with its domain and assumptions rather than treated as an unrestricted identity.

### How it could help you

1. Compare a short series expansion with a manually derived term.
2. Substitute sample values into a symbolic expression to check a derivation's implementation.

### Who it fits and what to expect

README identifies the New BSD license, with exceptions noted per file. Runs in compatible Python on major desktop OSs, without a GPU for small algebra. Large expressions can consume substantial time/RAM. Not a proof of every modeling assumption; branch choices, domains and simplification conventions matter. Numerical approximation and symbolic equality are different tasks.

### A small first step

15–25 minutes: follow https://docs.sympy.org/ using one symbol and the README's series example. Check the first few terms manually, substitute a value away from singularities, and inspect how assumptions change a simple expression. Keep the problem small rather than sending a long expression to an unrestricted simplifier.

## 4. Manim Community

Describe mathematical animations as explicit scenes and transformations.

### What it does

A programmatic animation engine for explanatory math videos. The community edition supplies scenes, geometric objects and transformations, with low-quality preview options and notebook integration.

### Why we recommend it

Recommended when a change over time communicates more than a static picture. It lets you control the sequence precisely, but good teaching still needs a clear explanation and correct labels.

### How it could help you

1. Animate a square changing into a circle while identifying the transformation.
2. Show a vector or geometric construction in a few deliberate steps.

### Who it fits and what to expect

MIT community edition; follow its own OS-specific instructions for Windows, macOS or Linux. Python, rendering dependencies and disk for video are required; formula rendering may add TeX/font needs. Render time grows with scene complexity. Not interchangeable with 3b1b/manim examples. More animation does not establish mathematical correctness.

### A small first step

20–30 minutes after setup: follow https://docs.manim.community/ and render the README's SquareToCircle at low quality. Change one color or timing and compare outputs. If dependencies are not ready, use the officially linked trial environment or spend the session assessing requirements rather than installing a large toolchain.

## 5. Quarto

Publish explanatory text with code outputs in a document project.

### What it does

A Pandoc-based technical publishing system with Markdown authoring, code execution via supported engines, cross-references and project-level websites/books. It integrates with Jupyter, Knitr and other authoring tools.

### Why we recommend it

Included below 10,000 stars because combining narrative, computation and multi-document publishing is a concrete use case distinct from a generic site theme. It is recently active; this is an explicit exception.

### How it could help you

1. Prepare a small report that keeps a chart's code near its explanation.
2. Render linked chapters with shared project settings instead of duplicating options.

### Who it fits and what to expect

README states MIT licensing for Quarto; dependencies and content have separate terms. CLI installers support Windows, macOS and Linux; Python/R/Julia engines are separate when used. PDF can need a TeX toolchain, fonts and extra disk. Not a guarantee of computational reproducibility: record environments and data. Executing documents runs embedded code.

### A small first step

20–30 minutes: follow https://quarto.org/docs/get-started/ and render a tiny Markdown document to HTML with headings and one cross-reference. Add a harmless code block only if its engine already exists. Check the output and execution settings; PDF dependencies can wait until a later trial.
