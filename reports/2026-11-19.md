## Where to start today

For handwritten PDF work, start with Xournal++. Choose SiYuan for block links, Trilium for a personal note tree, or Zettlr for a Markdown draft with citations. HedgeDoc is the shared-document alternative and the only star-threshold exception today.

## 1. SiYuan

Link individual ideas rather than only whole documents.

### What it does

SiYuan combines a Markdown WYSIWYG block editor, block references, backlinks, PDF annotation links, export and spaced-repetition flashcards. Its local workspace is the starting point; AI writing is optional.

### Why we recommend it

Try it when reusable paragraphs and linked study notes matter. A small connected notebook is a better evaluation than importing an entire archive.

### How it could help you

1. Connect a definition in reading notes to a worked example without copying the definition.
2. Create a few flashcards from a topic and check whether review fits your routine.

### Who it fits and what to expect

Desktop Windows/macOS/Linux and mobile apps, plus Docker hosting. AGPLv3 source; most features are free, but some require paid membership (https://b3log.org/siyuan/en/pricing.html). AI API usage may cost extra. Allow storage for assets and backups. Fits personal linked notes, less suited to a requirement that every feature be free or every note remain a plain Markdown file. Export is not the same as native storage; test portability first.

### A small first step

Spend 20 minutes creating two notes with one block reference, one image and one flashcard. Export to Markdown with assets and inspect the result before deciding to migrate.

## 2. Trilium Notes

Organize a growing note tree with links, attributes and multiple placements.

### What it does

Trilium offers rich-text and code notes, a deep hierarchy, full-text search, revisions and attributes. Cloning places the same note in multiple tree locations; a self-hosted server enables synchronization and browser access. Guide: https://docs.triliumnotes.org/ .

### Why we recommend it

Consider it when folder-like organization is useful but duplicating the same material across folders is becoming confusing.

### How it could help you

1. Place one shared project glossary under both a project and a reference branch using a cloned note.
2. Keep code snippets beside an explanation, then find the explanation using full-text search.

### Who it fits and what to expect

Free AGPLv3-or-later software for Windows/macOS/Linux; server web access and mobile frontends are available. Hosting and third-party services may cost money. Fits a structured personal database, less suited to plain-file-only workflows or effortless team collaboration. Budget disk space for the database, attachments and backups. Sync versions must match, including third-party mobile clients; old zadam migrations have version constraints. Back up before upgrades.

### A small first step

Use a stable release for a 25-minute trial: create three branches, clone one note into two branches, edit it and verify both placements change. Export a small sample and inspect it; leave server deployment for later.

## 3. Xournal++

Write diagrams and annotations directly over a page.

### What it does

Xournal++ supports pressure-sensitive pens, PDF backgrounds, highlighting, text, shapes, layers and export to PDF/PNG/SVG. Audio recording can accompany handwritten notes; optional LaTeX requires a working LaTeX installation.

### Why we recommend it

Choose it when equations, sketches or spatial annotations communicate more clearly than typed paragraphs.

### How it could help you

1. Annotate a lecture PDF with a diagram and questions on a separate layer.
2. Work through a derivation on ruled paper, then export a readable PDF for review.

### Who it fits and what to expect

Free GPL-2.0 software with desktop Linux, Windows and macOS packages. A stylus is useful but extra hardware costs money; large PDFs and audio need storage. Fits handwriting and annotation, not OCR search or a modern collaborative mobile notebook. The README says traditional .xopp files link PDF backgrounds rather than embedding them; retain the PDF with the notes and check your version's format. The separate mobile project has stalled, and macOS installation has caveats documented upstream.

### A small first step

Spend 20 minutes on a two-page PDF copy: add handwriting and a text label on separate layers, save the editable notes, export PDF, reopen both and check annotations. Keep the original PDF alongside the editable file.

## 4. Zettlr

Draft linked text with citations and publication-oriented exports.

### What it does

Zettlr combines Markdown writing, full-text search, snippets, Zettelkasten links and reference-manager integration. Export workflows use Pandoc and, for some profiles, LaTeX; official documentation is https://docs.zettlr.com/ .

### Why we recommend it

Recommend it when notes need to become a longer draft with citations and an export target, while keeping text-based authoring.

### How it could help you

1. Connect several reading notes to an outline and retrieve a passage using full-text search.
2. Prepare a short cited draft and inspect whether the intended Word or PDF export preserves the structure.

### Who it fits and what to expect

Free GPLv3 application for macOS, Windows and Linux; brand assets have separate restrictions. Official builds target 64-bit/ARM combinations listed in README, not 32-bit. Fits Markdown-oriented writing, less suitable for simultaneous team editing or exact word-processor layout during drafting. LaTeX-based export requires additional installation and disk space; templates and export dependencies must be configured, and citation metadata still needs checking.

### A small first step

In 25 minutes, open a small test folder, write two linked Markdown notes, add one citation from your bibliography if available, and try one export profile. Inspect headings and bibliography in the output; if a dependency is missing, record it rather than assuming every profile is ready.

## 5. HedgeDoc

Edit shared Markdown notes together in a browser.

### What it does

HedgeDoc provides real-time collaborative Markdown notes. The official README links a demo and installation guide at https://docs.hedgedoc.org/setup/getting-started/ . The current development branch is the incomplete HedgeDoc 2 rewrite; stable 1.x is maintenance-only.

### Why we recommend it

Included below 10,000 stars because shared live Markdown fills a distinct role beside personal notebooks. Evaluate stable behavior and deployment needs before choosing it for important records.

### How it could help you

1. Use an approved instance to outline meeting notes with headings and action items while participants edit together.
2. Prepare a small shared workshop handout and export or copy the Markdown for an independent archive.

### Who it fits and what to expect

Free AGPLv3 source; hosting, database operation, backups and administration still cost resources. Browser access works across desktop systems, subject to instance support. Fits shared Markdown documents, not an offline personal notebook or a feature-complete HedgeDoc 2 production promise. Instance permissions and retention matter. Do not put sensitive material into a public demo; use an instance you control or trust.

### A small first step

Spend 15–20 minutes on a permitted test instance with disposable text: create a note, open a second session, compare edits and access permissions, then preserve the Markdown independently. Server installation may take longer and is outside this short trial.
