## Where to start today

A library directory can start as a CSV in kepler.gl. Use Turf.js to count branches inside each district, or Leaflet to publish a simple locator with opening hours. MapLibre GL JS gives you control over how a basemap changes with zoom. Choose deck.gl when selecting a point should update a custom view in your application.

## 1. Leaflet

Put a short list of places on a map people can click.

### What it does

Add a tile layer to a web page, place markers at known coordinates and attach a popup to each marker. A visitor can pan, zoom and open the details on a phone or desktop.

### Why we recommend it

Choose it when a reader needs to find one place among a handful and read a few facts about it.

### How it could help you

1. Mark three public libraries and show opening hours on click.
2. Mark two park entrances and explain which one has a step-free path.

### Who it fits and what to expect

BSD-2-Clause browser library. A static page is enough for a small map. Tile services have separate terms, attribution and possible fees. A table is easier to scan if readers only need opening hours.

### A small first step

Allow 15 minutes. Adapt the official quick start to three libraries. Set each marker using latitude then longitude, add its name and hours, and check every popup at phone width.

## 2. MapLibre GL JS

Choose what readers see as they zoom from a city to a street.

### What it does

The browser renders vector tiles with GPU acceleration. A style defines the data sources and drawing layers, including how colors and symbols change with zoom.

### Why we recommend it

It fits a map with a deliberate visual hierarchy, where adding every label to the citywide view would obscure the main subject.

### How it could help you

1. Keep park outlines visible across the city and reveal entrance labels at street scale.
2. Use a muted base style so a cycle-route overlay remains legible.

### Who it fits and what to expect

Open-source browser library. Budget separately for licensed tiles, fonts, hosting and traffic. The device needs compatible graphics support. A small set of fixed markers seldom needs a custom vector style.

### A small first step

Allow 25 minutes. Start from the official display-a-map example. Add three park entrances as a GeoJSON source, give them a circle layer and set a minimum zoom. Zoom across the threshold twice to verify when the circles appear.

## 3. Turf.js

Answer a geographic question before deciding how to draw the result.

### What it does

Turf provides modular operations on GeoJSON, including distance, area and point-in-polygon tests. Results can feed a table, a map layer or another calculation.

### Why we recommend it

Use it when a map suggests an answer but the report needs a count that someone else can reproduce.

### How it could help you

1. Count public libraries inside a district boundary.
2. Calculate the straight-line distance between park entrances as a first comparison.

### Who it fits and what to expect

MIT-licensed library for browsers and Node.js. Small local GeoJSON inputs need no map service. Coordinates use longitude then latitude. Straight-line distance cannot establish walking time, and a boundary point needs a counting rule.

### A small first step

Allow 20 minutes. Draw a rectangular district, then place one point inside, one outside and one on an edge. Run booleanPointInPolygon twice with ignoreBoundary set to false and true. Record which count matches your report’s definition.

## 4. kepler.gl

Explore a table of locations before writing an application.

### What it does

Load location data into the web app, choose layers and fields, and apply filters. Its interface uses MapLibre GL and deck.gl for rendering and spatial aggregation.

### Why we recommend it

A good starting point for someone with a CSV who needs to inspect a pattern and discuss it with a colleague.

### How it could help you

1. Filter library branches by weekend opening and inspect which areas still have a branch.
2. Inspect a citywide point cloud for a stray coordinate before publishing the dataset.

### Who it fits and what to expect

MIT-licensed application accessible in a browser. Large imports consume memory and graphics resources. Hosting and basemap services may add costs. A visual cluster alone cannot explain why facilities are distributed that way.

### A small first step

Allow 15–20 minutes. Load a sample CSV with name, latitude, longitude and a weekend flag. Create a point layer, filter the flag, and check three displayed records against their source rows.

## 5. deck.gl

Give a web application direct control over dense map layers.

### What it does

Bind data records to layers such as points or polygons. Accessor functions determine position, color and size. Picking identifies the record under the pointer for a detail panel or tooltip.

### Why we recommend it

Choose it when a custom interaction must connect a map mark back to the application’s own data.

### How it could help you

1. Size library markers by annual visits and display the exact count on hover.
2. Overlay district polygons with branch points and show the selected branch in a side panel.

### Who it fits and what to expect

MIT-licensed JavaScript framework. It needs a supported browser and graphics backend. Test memory use and responsiveness on the intended device as data grows. For a small static locator its layer configuration adds work.

### A small first step

Allow 25–30 minutes in a prepared JavaScript project. Adapt a ScatterplotLayer example to five branches. Enable picking and display the branch name and visits, then check the two closest points against their records.
